# About this repository

This repository stores **Mickey's Personal AI Assistant Instructions** — a versioned persona/system-prompt document for a personal AI executive assistant (text, task, and voice interaction rules). See [`ASSISTANT_INSTRUCTIONS.md`](./ASSISTANT_INSTRUCTIONS.md) for the full instruction set.

`ASSISTANT_INSTRUCTIONS.md` defines a persona for a separate, downstream assistant product (e.g. to be pasted into that product's system-prompt configuration). It is **not** a directive for Claude Code's own behavior in this repository — when working here, Claude Code should follow its normal engineering conventions rather than adopting the Mickey persona.
